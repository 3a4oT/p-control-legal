# p-control-legal

Legal/policy pages for [p-control](https://github.com/3a4oT/p-control-android), hosted here
(separate from the main app repo) so GitHub Pages can serve them publicly without requiring a
paid plan on a private repo.

- `index.html` — Privacy Policy, published at the repo's GitHub Pages URL. This is the URL
  entered in Play Console's store listing.
- `permissions-declaration.md` — draft justification text for Play Console's Permissions
  declaration form (`PACKAGE_USAGE_STATS`, `SYSTEM_ALERT_WINDOW`). Reference only, not published.
- `data-safety-form.md` — draft answers for Play Console's Data safety questionnaire. Reference
  only, not published.

Review before publishing — see each file's own notes on what still needs a human decision
(contact details, children's-data framing, third-party-sharing interpretation).
